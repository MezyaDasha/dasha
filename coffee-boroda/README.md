# COFFEE BORODA — сайт кав'ярні

Односторінковий сайт з 3D-сценою (Three.js) і motion-анімаціями (GSAP + ScrollTrigger, Lenis).

## Запуск

Потрібен будь-який статичний сервер (ES-модулі не працюють через `file://`):

```bash
cd coffee-boroda
python3 -m http.server 8000
# відкрити http://localhost:8000
```

Для хостингу (GitHub Pages, Netlify, Vercel) достатньо залити папку `coffee-boroda/` як є.

## Що всередині

- `index.html` — розмітка всіх секцій (герой, про нас, осінні еклери, меню, події, адреси, рейтинг, футер)
- `style.css` — стилі, кольори-токени в `:root`
- `main.js` — 3D-сцена (чашка з латте-артом, пара на шейдері, кавові зерна) і всі анімації
- `vendor/` — бібліотеки локально (three 0.160, gsap 3.12.5, lenis 1.1.13), CDN не потрібен

Положення 3D-чашки для кожної секції задається масивом `sceneKeys` у `main.js`.
